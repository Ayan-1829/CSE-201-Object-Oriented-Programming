Classes, objects and constructors

public class Student {
    private String name;                  // field
    private static int count = 0;         // class-wide
    public Student() { this("Unknown"); } // constructor chaining
    public Student(String name) { this.name = name; count++; }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    @Override public String toString() { return "Student " + name; }
}
Student s = new Student("Ann");
  • No constructor written → Java adds a default no-arg one.
  • Fields default to 0 / 0.0 / false / null; local variables have no default.

Inheritance and polymorphism

class Dog extends Animal {
    Dog(String n) { super(n); }                 // first statement
    @Override String sound() { return "Woof"; }
    String both() { return super.sound() + sound(); }
}
Animal a = new Dog("Rex");        // upcast (automatic)
a.sound();                        // Dog's version runs
if (a instanceof Dog d) d.fetch(); // pattern + downcast

Constructors run top-down (Object → Animal → Dog). A class extends one class and implements many interfaces.

JavaFX

public class App extends Application {
    public void start(Stage stage) {
        Button b = new Button("OK");
        b.setOnAction(e -> System.out.println("clicked"));
        VBox root = new VBox(10, new Label("Hi"), b);
        stage.setScene(new Scene(root, 300, 200));
        stage.show();
    }
    public static void main(String[] a) { launch(a); }
}

Layouts: HBox, VBox, FlowPane, GridPane (add(node, col, row)), BorderPane (setTop/Center/…), StackPane. Drawing: Canvas → getGraphicsContext2D() → fillRect, fillOval, strokeLine, fillText. Animation: AnimationTimer.handle(now).
