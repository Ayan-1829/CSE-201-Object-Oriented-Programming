# CSE 201 · Object Oriented Programming

Interactive slide-deck course notes for Object Oriented Programming in Java.

### 🌐 Live site: **[https://ayan-1829.github.io/CSE-201-Object-Oriented-Programming/](https://ayan-1829.github.io/CSE-201-Object-Oriented-Programming/)**

Also on the site: [Practice problems](https://ayan-1829.github.io/CSE-201-Object-Oriented-Programming/practice.html) · [Java quick reference](https://ayan-1829.github.io/CSE-201-Object-Oriented-Programming/reference.html) · [Lab projects](https://ayan-1829.github.io/CSE-201-Object-Oriented-Programming/projects.html)

## What’s inside

- 13 topic decks that follow the lectures, from Java basics to threads, GUI, JDBC and Spring
- Step-through code tracer that shows the stack, heap, static area and console line by line
- UML, memory and flow diagrams, live demos and a quiz in every topic
- Practice problems with answers, a searchable Java quick reference and lab projects with saved checklists

## Using the slides

| Key | Action |
|---|---|
| <kbd>←</kbd> <kbd>→</kbd> / <kbd>Space</kbd> | previous / next slide |
| <kbd>Home</kbd> / <kbd>End</kbd> | first / last slide |
| <kbd>F</kbd> | full screen |
| <kbd>M</kbd> | slide list |
| ✏️ button | draw on the slide |

The address bar shows `#s=N` for slide N, so you can link straight to any slide. Light and dark themes are built in.

## Run it locally

No build step or server is needed: download or clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/Ayan-1829/CSE-201-Object-Oriented-Programming.git
```

