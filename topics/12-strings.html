Before we start

Why this matters

What is 30 factorial? A long gives you −8,764,578,968,847,253,504. Clearly wrong — so how do banks and cryptography handle numbers with hundreds of digits?

One answer is to store the digits in a String and do the arithmetic yourself, digit by digit, exactly as you learnt at school. Java’s BigInteger does the same thing internally.

First we study String itself: why == can lie, why strings never change, and the methods you will use in almost every program.

Concept 1 of 5

The String class and the string pool

The String class and the string pool

String a = "Hi";               // pool
String b = "Hi";               // same pooled object
String c = new String("Hi");   // new heap object
char[] cs = {'J', 'a', 'v', 'a'};
String d = new String(cs);     // "Java"
String e = String.valueOf(42); // "42"
  • String is a class, but literals get special treatment: identical literals share one object in the string pool.
  • Strings are immutable: no method changes a String; methods return a new one.
  • Immutability makes strings safe to share between variables and threads.

Concept 2 of 5

Comparing strings

String a = "apple", b = "Apple";
a == b                    // compares references
a.equals(b)               // false: content, case-sensitive
a.equalsIgnoreCase(b)     // true
a.compareTo(b)            // 32  ('a' 97 − 'A' 65)
"apple".compareTo("banana")  // -1  ('a' − 'b')
"app".compareTo("apple")     // -2  (length 3 − 5)
  • Never use == to compare text; use equals.
  • compareTo returns negative, 0 or positive for dictionary order: it subtracts the first differing characters, or the lengths if one is a prefix of the other.
  • Guard against null with "yes".equals(input) instead of input.equals("yes").

Concept 4 of 5

StringBuilder

StringBuilder sb = new StringBuilder("GUB");
sb.append(" CSE").append(201);   // "GUB CSE201"
sb.insert(3, ",");               // "GUB, CSE201"
sb.reverse();                    // "102ESC ,BUG"
sb.setCharAt(0, '9');            // "902ESC ,BUG"
sb.deleteCharAt(sb.length() - 1);// "902ESC ,BU"
String result = sb.toString();
  • StringBuilder is a mutable sequence of characters: its methods change the same object.
  • Joining strings with + in a loop creates a new String every time — slow for long loops.
  • StringBuffer is the older, synchronized (thread-safe) version.

Concept 5 of 5

Big numbers stored as Strings

TypeLargest value
int2,147,483,647 (10 digits)
long9,223,372,036,854,775,807 (19 digits)
String of digitsas many digits as memory allows
  • Store each number as a String of digits; the last character is the ones digit.
  • Work from right to left: a.charAt(i) - '0' converts a digit character to its value.
  • Keep a carry (addition) or borrow (subtraction), and build the answer with a StringBuilder, reversing at the end.
static String add(String a, String b) {
    StringBuilder sb = new StringBuilder();
    int i = a.length() - 1, j = b.length() - 1, carry = 0;
    while (i >= 0 || j >= 0 || carry > 0) {
        int d1 = i >= 0 ? a.charAt(i--) - '0' : 0;
        int d2 = j >= 0 ? b.charAt(j--) - '0' : 0;
        int sum = d1 + d2 + carry;
        sb.append(sum % 10);
        carry = sum / 10;
    }
    return sb.reverse().toString();
}

Big-number addition, column by column

Code example

Multiplying big numbers

static String multiply(String a, String b) {
    int[] r = new int[a.length() + b.length()];
    for (int i = a.length() - 1; i >= 0; i--)
        for (int j = b.length() - 1; j >= 0; j--) {
            int p = (a.charAt(i) - '0') * (b.charAt(j) - '0') + r[i + j + 1];
            r[i + j + 1] = p % 10;        // this column
            r[i + j] += p / 10;           // carry to the left
        }
    StringBuilder sb = new StringBuilder();
    for (int d : r) if (!(sb.length() == 0 && d == 0)) sb.append(d);
    return sb.length() == 0 ? "0" : sb.toString();
}
System.out.println(multiply("123456789", "987654321"));
System.out.println(multiply("12345678901234567890", "98765432109876543210"));
Output
121932631112635269
1219326311370217952237463801111263526900

Digit i of a times digit j of b lands in column i + j + 1 of the result — the same shifted rows you write on paper.

static boolean isPal(String s) {
    s = s.toLowerCase();
    for (int i = 0, j = s.length() - 1; i < j; i++, j--)
        if (s.charAt(i) != s.charAt(j)) return false;
    return true;
}

5. Write subtract(String a, String b) for a ≥ b ≥ 0.
Show the answer
static String subtract(String a, String b) {
    StringBuilder sb = new StringBuilder();
    int borrow = 0;
    for (int i = a.length() - 1, j = b.length() - 1; i >= 0; i--, j--) {
        int d = a.charAt(i) - '0' - borrow - (j >= 0 ? b.charAt(j) - '0' : 0);
        borrow = d < 0 ? 1 : 0;
        sb.append(d < 0 ? d + 10 : d);
    }
    String r = sb.reverse().toString().replaceFirst("^0+(?!$)", "");
    return r;
}
6. When should you use StringBuilder instead of String?
Show the answer
When you build a string step by step, especially inside loops, to avoid creating many temporary String objects.

Summary

Summary

  • String literals share objects in the string pool; new String always creates a new object.
  • Strings are immutable — methods return new strings; compare text with equals, order with compareTo.
  • Key methods: length, charAt, indexOf, substring, split, replace, trim, toUpperCase.
  • StringBuilder is mutable and efficient for building strings in loops.
  • Numbers of any size can be stored as digit strings and added or multiplied column by column; BigInteger/BigDecimal do it for you.
