Before we start

Why this matters

Every app you use has buttons, text boxes and pictures, and saves your data somewhere. How much of that can you already build with the OOP you know?

All of it. A JavaFX window is a tree of objects; a button click is an event object delivered to a method; a database row becomes a Java object. Classes, inheritance, interfaces and lambdas are everywhere.

This last topic tours the libraries you will use for real projects: JavaFX for interfaces and graphics, JDBC for databases and Spring for back-end services.

Concept 1 of 5

A JavaFX application

A JavaFX application

public class HelloFX extends Application {
    @Override
    public void start(Stage stage) {
        Label msg = new Label("Hello, JavaFX");
        Button btn = new Button("Click me");
        btn.setOnAction(e -> msg.setText("Clicked!"));

        VBox root = new VBox(10, msg, btn);    // layout pane
        stage.setScene(new Scene(root, 300, 150));
        stage.setTitle("First FX app");
        stage.show();
    }
    public static void main(String[] args) { launch(args); }
}
  • Extend Application and override start(Stage); launch() calls it for you.
  • Everything you see is a Node object in a tree.

Event handling

// 1. lambda (most common)
btn.setOnAction(e -> System.out.println("clicked"));

// 2. anonymous class implementing EventHandler<ActionEvent>
btn.setOnAction(new EventHandler<ActionEvent>() {
    @Override
    public void handle(ActionEvent e) { System.out.println("clicked"); }
});

// other events
field.setOnKeyPressed(e -> System.out.println(e.getCode()));
canvas.setOnMouseClicked(e -> System.out.println(e.getX() + "," + e.getY()));

Code example

Designing a simple interface

GridPane g = new GridPane();
g.setHgap(10); g.setVgap(8); g.setPadding(new Insets(16));

TextField marks = new TextField();
marks.setPromptText("0 - 100");
Button calc = new Button("Get grade");
Label result = new Label();

g.add(new Label("Marks:"), 0, 0);   g.add(marks, 1, 0);
g.add(calc, 1, 1);
g.add(result, 1, 2);

calc.setOnAction(e -> {
    try {
        int m = Integer.parseInt(marks.getText().trim());
        result.setText(m >= 80 ? "A+" : m >= 70 ? "A" : m >= 60 ? "A-" : "Below A-");
    } catch (NumberFormatException ex) {
        result.setText("Please enter a whole number");
    }
});
stage.setScene(new Scene(g));

Concept 4 of 5

Connecting to a database with JDBC

  1. Add the driver (e.g. MySQL Connector/J) to the project.
  2. DriverManager.getConnection(url, user, password) opens a Connection.
  3. Create a PreparedStatement with ? placeholders and fill them with setString, setInt, …
  4. executeQuery() returns a ResultSet (SELECT); executeUpdate() returns a row count (INSERT/UPDATE/DELETE).
  5. Close everything — try-with-resources does it for you.

Code example

Inserting rows safely

String url = "jdbc:mysql://localhost:3306/gub";
String sql = "INSERT INTO students(name, dept, cgpa) VALUES (?, ?, ?)";
try (Connection con = DriverManager.getConnection(url, "root", "secret");
     PreparedStatement ps = con.prepareStatement(sql)) {
    ps.setString(1, "Farhan");
    ps.setString(2, "CSE");
    ps.setDouble(3, 3.80);
    int rows = ps.executeUpdate();
    System.out.println(rows + " row inserted");
} catch (SQLException e) {
    System.out.println("DB error: " + e.getMessage());
}
Output
1 row inserted
Security: Never build SQL by joining user input: "… WHERE name = '" + input + "'" lets a user type ' OR '1'='1 and read every row (SQL injection). PreparedStatement parameters are always treated as data.

Concept 5 of 5

Introduction to Spring

@SpringBootApplication
public class GradeApp {
    public static void main(String[] args) {
        SpringApplication.run(GradeApp.class, args);
    }
}

@Service
class GradeService {
    String letter(int m) { return m >= 80 ? "A+" : m >= 70 ? "A" : "below A"; }
}

@RestController
class GradeController {
    private final GradeService service;
    GradeController(GradeService service) {   // injected by Spring
        this.service = service;
    }
    @GetMapping("/grade/{marks}")
    String grade(@PathVariable int marks) { return service.letter(marks); }
}
Browser
GET http://localhost:8080/grade/85   →   A+
  • Spring is the most widely used Java framework for back-end and web applications.
  • Inversion of Control / Dependency Injection: you declare what an object needs (a constructor parameter); Spring creates the objects and wires them together.
  • Spring Boot adds sensible defaults and an embedded web server, so a REST API is a few annotated classes.
  • Spring Data JPA maps classes to database tables, replacing most hand-written JDBC.

Try each one on paper first, then check your answer.

1. What are Stage, Scene and Node in JavaFX?
Show the answer
Stage is the window; Scene is the content shown in it; Nodes are the objects (panes, controls, shapes) in the scene graph tree.
2. Write code that draws a red circle of radius 40 centred at (100, 100) on a GraphicsContext gc.
Show the answer
gc.setFill(Color.RED);
gc.fillOval(60, 60, 80, 80);   // top-left corner, width, height
3. Why must slow work (like a database query) not run inside an event handler on the JavaFX Application Thread?
Show the answer
The UI thread would be blocked, so the window freezes. Run the work in a background thread (e.g. a Task) and update the UI with Platform.runLater.

Practice (2 of 2)

4. What is the difference between executeQuery and executeUpdate?
Show the answer
executeQuery runs a SELECT and returns a ResultSet; executeUpdate runs INSERT/UPDATE/DELETE and returns the number of affected rows.
5. Explain dependency injection in one sentence.
Show the answer
Instead of an object creating the objects it needs, they are passed to it (usually through the constructor) by a container such as Spring.
6. How does an AnimationTimer create smooth motion?
Show the answer
Its handle(now) method is called about 60 times per second; each call updates positions slightly and redraws the frame.

Summary

Summary

  • A JavaFX app is a Stage showing a Scene whose root is a tree of nodes: layout panes and controls.
  • Layouts (HBox, VBox, GridPane, BorderPane, FlowPane, StackPane) position controls; events call handlers, usually lambdas.
  • Canvas + GraphicsContext draw shapes and text; AnimationTimer redraws ~60 times a second for animation.
  • JDBC: Connection → PreparedStatement → ResultSet, closed with try-with-resources.
  • Spring Boot builds back-end services from annotated classes wired together by dependency injection.
