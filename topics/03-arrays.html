Before we start

Why this matters

A class has 60 students. Do you really need 60 separate variables to store their marks?

An array stores many values of the same type under one name, each reached by an index. Once marks sit in an array, one loop can find the highest, the average or sort them.

You will also see a surprise: arrays are objects, so copying an array variable does not copy the array.

  • Indexes run from 0 to length − 1.
  • New arrays are filled with default values: 0, 0.0, false or null.

Concept 2 of 5

Arrays are objects: copying a reference

Arrays are objects: copying a reference

  • b = a → both names refer to the same array (aliases). A change through b is visible through a.
  • a.clone() or Arrays.copyOf(a, a.length) creates a new array with the same values.
  • a == b compares references. Use Arrays.equals(a, b) to compare contents.

Concept 4 of 5

Sorting algorithms

AlgorithmIdeaComparisons (worst)
Bubble sortCompare neighbours and swap if out of order. After pass k, the k largest values are in place at the end.n(n−1)/2
Selection sortFind the minimum of the unsorted part and swap it to the front.n(n−1)/2, but at most n−1 swaps
Insertion sortTake the next value and shift larger values right until its place is found — like sorting playing cards.n(n−1)/2; almost linear on nearly-sorted data
// bubble sort
for (int pass = 0; pass < a.length - 1; pass++)
    for (int j = 0; j < a.length - 1 - pass; j++)
        if (a[j] > a[j + 1]) { int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t; }
Library: In real programs use Arrays.sort(a), which is fast (O(n log n)).

Concept 5 of 5

Searching

static int linear(int[] a, int key) {
    for (int i = 0; i < a.length; i++)
        if (a[i] == key) return i;
    return -1;                     // not found
}

static int binary(int[] a, int key) {  // a must be sorted
    int lo = 0, hi = a.length - 1;
    while (lo <= hi) {
        int mid = (lo + hi) / 2;
        if (a[mid] == key) return mid;
        if (a[mid] < key) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}

Needs sorted data?NoYes

Useful java.util.Arrays methods

Worked example 1

Reverse an array in place.
Show the solution
for (int i = 0, j = a.length - 1; i < j; i++, j--) {
    int t = a[i]; a[i] = a[j]; a[j] = t;
}
Swap the two ends and move inwards; stop when the indexes meet. Only n/2 swaps.

Summary

Summary

  • An array stores a fixed number of same-typed values; indexes go from 0 to length − 1.
  • Array variables hold references: assignment creates aliases; clone() or Arrays.copyOf makes copies.
  • A 2-D array is an array of arrays; rows may differ in length (jagged).
  • Bubble, selection and insertion sort all take about n²/2 comparisons; use Arrays.sort in practice.
  • Linear search works on any array (O(n)); binary search needs sorted data but is O(log n).
